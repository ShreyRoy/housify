# Data provenance and licensing

Discogs community releases data, snapshot 2026-11-01, downloaded from https://data.discogs.com/. The official downloadable-data index states CC0 No Rights Reserved. License: https://creativecommons.org/publicdomain/zero/1.0/.

The generated catalog is an adapted, selected representation of those bulk catalog facts. It retains snapshot/source IDs and release URLs. Images, audio, marketplace information and user profiles are not imported. Discogs is a trademark of Zink Media, LLC; this experiment is not affiliated with, sponsored or endorsed by Discogs. API terms should be reviewed separately before using API responses in place of bulk data.

Benchmark references are independently selected factual song/title/version/duration/genre observations with source links, not copied articles or retailer databases. Where independent sources conflict or genre/identity remains unadjudicated, the evaluation marks that limitation rather than treating the reference as certain. The reference observations are not used as classifier catalog annotations.

Synthetic test fixtures are separately authored examples. They are used for engineering tests only. No Spotify data is included in benchmark or catalog files. These data notices do not relicense project source code or third-party article text.
